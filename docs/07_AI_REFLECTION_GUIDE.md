## Recording AI use

For each substantive prompt, record the request, AI contribution, accepted edits,
corrections, verification and remaining limits. Distinguish agent-run checks from
checks performed independently by the student. Historical entries keep the scope
and decisions that applied when they were written.

## T10 reflection

Write at least 500 words for each participating member if this remains part of the
submission requirements. Cover the development tasks where AI was used, how the
output was assessed, concrete mistakes and their correction, and lessons learned.
Use examples from the actual log and explain the code and mechanisms yourself.

## Suggested structure

1. Project responsibilities and the reasons for using AI.
2. Representative prompts and the output they produced.
3. Decisions accepted, revised or rejected, with reasons.
4. Verification evidence from code review, Console demos and retained checks.
5. Understanding gained, limitations and improvements to future AI use.
