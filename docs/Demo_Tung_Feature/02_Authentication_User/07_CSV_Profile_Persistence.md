# CSV Profile Persistence

- Dùng để đăng nhập ở một lần chạy tiếp theo và kiểm tra profile đã cập nhật vẫn còn trong CSV.
- Luồng xử lý trong code `MainController → AuthController.login / getCurrentUser → AuthService → FanRepository`.
- Mỗi lần nhập bên dưới phải nhấn Enter. Dòng Enter trống là không gõ ký tự.

[Chuẩn bị dữ liệu](../00_CHUAN_BI.md) · [Thứ tự chạy đầy đủ](../01_THU_TU_DEMO.md) · [Danh mục tính năng](../README.md)

## Điều kiện demo

- Dùng CORE_DIR từ file chuẩn bị. Chạy các flow theo thứ tự toàn cục để có đúng ID và trạng thái.
- Những flow tạo sân/ghế/trận, mua vé hoặc gửi refund là tiền đề cho các flow dùng lại bản ghi đó.
- Có thể mở file theo từng tính năng để tra cứu; số Flow giữ thứ tự thực thi của buổi demo.

## Flow 138 — CSV Persistence - login lại thấy profile đã lưu

- Bắt đầu ở Main của CORE_DIR sau [Flow 137](../10_Admin_Monitoring/02_View_Audit_Log.md#flow-137).

```text

1. Browse As Guest (Search matches & View seat availability)
2. Login As Fan
3. Login As Staff (Admin, Seller, Gate)
4. Register Fan Account
0. Exit System
Choose option:
```

### Toàn bộ lượt nhập theo thứ tự

```text
1. 2
2. flow.fan@example.com
3. FlowPass123
4. 1
5. 0
```
